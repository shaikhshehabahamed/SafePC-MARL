# SafePC-MARL: Safe Preference-Conditioned Multi-Agent Reinforcement Learning for Multi-Objective Manufacturing Control

Manufacturing cells that must balance throughput, energy use, and operator ergonomic load face a control problem with no single optimal operating point, because the best trade-off shifts with production priorities that are rarely stated explicitly. This paper presents SafePC-MARL, a safe preference-conditioned multi-agent reinforcement learning framework that learns one policy spanning the full trade-off space, enforces a per-cell safety limit, and infers the operator's preference from observed behavior instead of explicit input. We validate the framework on the AI4I 2020 predictive-maintenance benchmark dataset, partitioned into three simulated manufacturing cells with distinct operating profiles. Across a 45-point preference simplex, SafePC-MARL improves the hypervolume indicator by 1,971.8% over the strongest baseline, degrades by only 7.09% on average under runtime preference switching, and recovers the operator's true preference to a mean absolute error of 0.102 after three simulated production shifts. It also attains a lower mean safety cost than every baseline while holding throughput constant. These results show that safe, multi-objective, multi-agent manufacturing control with runtime preference adaptation is achievable without sacrificing production rate.
